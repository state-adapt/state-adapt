# Curated API docs

The `sections.ts` files under `docs/api` are hand-curated lists of the APIs we want to feature. They are **not** lists of everything TypeDoc finds. Do not add a symbol just because it is exported, documented, new, or present in TypeDoc output. Add one only when it belongs in the public API navigation and package overview.

Each `sections.ts` controls:

- which API pages are copied into the public docs;
- their groups and order on the package's `index.md` page;
- their groups and order in the API sidebar.

The adjacent `index.md` is the hand-written package landing page. Keep the short introduction, peer dependencies, and any package-specific notes there. Its Vue template renders the curated sections; it is not generated by TypeDoc.
